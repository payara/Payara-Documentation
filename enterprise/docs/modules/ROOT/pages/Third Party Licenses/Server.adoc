== Introduction

The Payara Platform incorporates third-party licensed software packages. Some of these packages have distribution restrictions and some have only reporting requirements. This document lists the third-party licensed software packages distributed with the Payara Platform and the license under which each is made available.

In addition to the licenses listed herein, there are numerous copyright notices by individual contributors who contribute their code under one of the licenses below, with the requirement that the copyright notices be retained. The disclaimers and copyright notices provided are based on information made available to the Payara Foundation by the third-party licensors listed.

For portions of the software that are licensed under open source license agreements that require Payara to make the source code available, Payara will, upon request, provide a complete machine-readable copy of such source code on a medium customarily used for software interchange, for a charge no more than the cost of physically performing source distribution. Please contact the Payara Foundation for further information.
