= Payara Platform Third-Party Licenses

This page provides a detailed list of third-party dependencies used within the Payara Platform, including the Maven GAV (GroupId, ArtifactId, Version) coordinates for each dependency.

The information on this page can be used to identify the specific versions of third-party libraries included in a particular Payara Platform distribution or release.

NOTE: This page is intended as a reference for dependency tracking, license verification, and auditing purposes.
